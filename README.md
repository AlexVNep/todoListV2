# todoListV2

# Version 2 of my To Do List

# Description

This is a simple Todo List application built using JavaScript, Webpack, and the Web Storage API. The app allows users to create, manage, and organize their tasks efficiently across multiple projects. It incorporates object-oriented programming principles.

# Features

Create, edit, and delete todo items.

Each todo item has the following properties:

Title

Description

Due Date

Priority Level

Organize todos into different projects.

Default project for initial todos.

View all projects and their respective todos.

Mark todos as complete.

Persistent storage using localStorage.

# Technologies Used

JavaScript (ES6+)

Webpack

HTML & CSS

Web Storage API (localStorage)

# Installation & Usage

Clone the repository:

git clone git@github.com:AlexVNep/todoListV2.git

Navigate to the project folder:

cd todo-list

Install dependencies:

npm install

Build and start the development server:

npm run start

Open the application in your browser.
